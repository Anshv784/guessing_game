# guessing game

the guessing game from chapter 2 of the rust book, done for the turbin3 builders cohort.

the program picks a random number between 1 and 100 and you keep guessing until you get it. it tells you if your guess is too small or too big. anything that isn't a number gets ignored.

## run

```
cargo run
```

uses the `rand` crate (0.8.5) for the secret number.
